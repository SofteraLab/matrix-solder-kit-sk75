# Якщо матриця не світиться

| Симптом | Перевірка |
| --- | --- |
| Нічого не світиться | Кабель USB-C дає 5 В; вимикач увімкнений; немає КЗ біля USB |
| Немає демо-анімації | Орієнтація ATtiny; пайка MAX7219; наявність прошивки |
| Один темний LED | Полярність цього 1206; обидві площадки; LED не перегрітий |
| Темний рядок / стовпець | Містки чи холодні стики на MAX7219; пайка рядка/стовпця матриці |
| Плата гріється | Зніміть USB одразу; огляньте містки на MAX7219 / ATtiny / USB-C |
| Не програмується | Орієнтація ISP-кабелю (мітка RST); живлення під час програмування |
| Друга матриця темна | З’єднання GND · OUT · 5V · CS · IN · SCK; коректне живлення обох плат |

:::caution Живлення
Якщо плата гріється одразу після USB — спочатку вимкніть. Потім шукайте містки припою.
:::

Коли пишете в підтримку, вкажіть код набору **SK-75**, що саме не працює (анімація / піксель / ISP / додаткова матриця) і чіткі фото обох сторін.
