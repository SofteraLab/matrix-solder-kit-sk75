# Схема і блоки

Навчальні слайди набору: SPI-керування, мультиплексування DIG/SEG і каскадування.

## Схема — MAX7219 + матриця LED

![Схема MAX7219 + матриця LED](./assets/images/uk/schematic-max7219.jpg)

USB **5 В** живить **ATtiny** (TinyXX) і **MAX7219**. МК спілкується по SPI (**CS · DIN · SCK**). Драйвер сканує матрицю через **DIG0–DIG7** (рядки) і **SEG0–SEG7** (колонки). **RSET** задає струм сегмента.

## Мультиплексування 8×8

![Мультиплексування матриці 8×8](./assets/images/uk/multiplexing.jpg)

- **DIG** = рядки (сканування)  
- **SEG** = стовпці (сегменти)  
- MAX7219 швидко перемикає рядки — око бачить суцільну картинку  
- МК **не** керує кожним LED окремо  

## Повна блок-схема

![Повна блок-схема комплекту](./assets/images/uk/block-diagram.jpg)

Додаткові матриці каскадують **OUT → IN** (до **8** шт.). Яскравість — через **RSET**.

:::caution Інтелектуальна власність
Ці картки пояснюють куплений набір. Повна виробнича схема і Gerber публічно не викладаються.
:::
