# Firmware

Matrix Solder Kit SK-75 is driven by an **ATtiny** microcontroller (**85 / 45 / 25**, SOIC-8) and an **MAX7219** LED matrix driver.

The board ships with demo firmware that animates the 8×8 (64) LED 1206 matrix after USB Type-C 5 V power is applied.

You can reprogram the MCU through the dedicated **ISP / RST** header.

Firmware sources and production binaries are Softera Lab IP and are **not** published in this public repository.  
Assembly and first power-on: `docs/en/02-getting-started.md` (EN) · `docs/02-getting-started.md` (UA).
